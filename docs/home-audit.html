Home Screen Audit

Every element on the home screen, sorted by what should happen to it. Grouped by verdict rather than by position, because the useful question is what needs deciding — not what sits nearest the top.

Reviewed Aug 22, 2026 · after the Trends + first-run intro ships

If it’s on the home screen it should open something on tap. If there’s nothing worth opening, it shouldn’t be competing for the space.

That cuts both ways, which is what makes it useful as a test rather than a to-do list.

Where it stands now

Last review the rule produced two unfinished features and one corpse. This review, both features are shipped — the sparkline opens the Trends screen and the Lifetime Score opens its breakdown — and the persona-block decision is made: it’s cut, because its content now lives in the score sentence.

What’s left is small and unambiguous: one real link worth doing (Miles → Trends, now that Trends exists), a couple of optional ones, and a dead-markup cleanup (persona-badge plus the hidden persona block). The home screen went from half-built to wired, with a short tidy-up list — no product decisions outstanding.
